# TREK 空白旅行模板

入口：`/TREK/template/`。此目录与原行程独立，不读取原行程的 `data.js`、收藏地点或固定云端记录。

- 新建 1–90 天行程，设置 1–8 位同行者。
- 日历可编辑每日城市、住宿、备注；时间轴可增删事项、设置时间、完成状态和 Google Maps 链接。
- 交通住宿、双人或多人行李独立管理；共用物品显示提供者与复核状态。
- 城市和路线地图分别可选。城市坐标可手填，也可在启用地图后点击地图创建；地图连线只表示顺序。
- 未发布的行程只保存在当前浏览器。可随时导出 JSON 备份，导入时会创建新行程。
- 使用已有授权账号登录后可发布共享链接。模板行程使用 `journey-<UUID>` 云端记录，不会覆盖原行程。知道链接的人可查看；授权账号可编辑。

公开地图底图由 OpenStreetMap 提供。若底图暂不可用，城市列表和 Google Maps 链接仍可使用。
